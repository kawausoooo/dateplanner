# タイトルページ仕様書

## 1. 対象と目的
- 対象機能: タイトルページ
- 主変更ファイル: `/home/yamanashi/dateplanner/src/features/title/TitlePage.tsx`
- 関連ファイル:
  - `/home/yamanashi/dateplanner/src/styles/global.css`
  - `/home/yamanashi/dateplanner/src/features/person-selector/PersonSelectorPage.tsx`
  - `/home/yamanashi/dateplanner/src/shared/ui/PageLayout.tsx`

目的は、アプリ起動時に表示されるタイトルページを、`donuts` の世界観に合う導入画面として統一し、クリックだけで人物選択画面へ遷移できるようにすること。

## 2. 要件（必須）
1. アプリロゴをページ中央の背景に表示する。
2. タイトルページには、アプリ名とキャッチフレーズを中心に表示する。アプリ名はページの約1/6サイズ感を目安にし、キャッチフレーズはアプリ名の下に配置する。
3. タイトルページの背景は、シンプルで視覚的に魅力的なデザインにする。
4. ボタンは置かず、画面クリックで人物選択画面へ遷移する。
5. アプリテーマに合わせた統一感を持たせ、一色の画面の中心にロゴが出る構成にする。
6. タイトルページにはページタイトルを表示しない。
7. タイトルページ表示時にフェードインさせる。
8. 文言は固定で、アプリ名 `donuts`、キャッチフレーズ `ドーナッツ～恋人相性チェッカー～` とする。
9. タイトルとキャッチフレーズのフォントはイタリックにする。
10. タイトルロゴはドーナッツをモチーフにし、2色以上を使ったわかりやすく可愛らしいデザインにする。

## 3. 画面仕様
- レイアウト:
  - 画面全体をクリック可能領域にする。
  - 画面中央に、背景ロゴと前景テキストを重ねる。
- 表示要素:
  - 背景中央: ドーナッツモチーフのロゴ（多色）
  - 前景中央: `donuts`
  - 前景下: `ドーナッツ～恋人相性チェッカー～`
- 遷移:
  - クリックで `/people` に遷移
  - Enter/Space キーでも `/people` に遷移
- タイトル表示:
  - `PageLayout` の `showTitle={false}` により `h1` 非表示
- アニメーション:
  - 初回表示時にフェードイン（`opacity` と `translateY`）を適用

## 4. デザイン仕様
- 背景:
  - 一色背景（例: `#ffffcc`）を使用
  - 過度な装飾は避ける
- ロゴ:
  - ドーナッツ形状（円 + 穴）を判別できる構成
  - 2色以上を使用（例: 生地色 + アイシング色 + スプリンクル色）
  - 中央配置、低不透明度で前景文字の視認性を確保
- タイポグラフィ:
  - `title-name` と `title-tagline` に `font-style: italic`
  - フォールバックを含むフォントスタックを定義
  - `title-name` は表示領域に対して約1/6を目安に大きく設定（`clamp`推奨）
  - `title-tagline` は `title-name` 直下に配置し、視線誘導を維持
- 統一感:
  - 人物選択画面と角丸・余白・色調の方向性を合わせる

## 5. 実装方法（推奨）
1. `TitlePage.tsx`
- `PageLayout` を `showNav={false}`、`showTitle={false}` で使用する。
- クリック可能なラッパー（例: `.title-hero`）に `onClick` を設定して `/people` へ遷移する。
- `role="button"`、`tabIndex={0}`、`onKeyDown`（Enter/Space）を設定する。
- テキストを `donuts` / `ドーナッツ～恋人相性チェッカー～` に固定する。
- コンテナに `fade-in` クラスを付与する。

2. `global.css`
- `.title-hero`:
  - 一色背景、中央寄せ、角丸、全体クリック可能スタイル
- `.title-hero::before` または `.title-logo`:
  - ドーナッツロゴを中央背景として描画
  - 2色以上で可愛い配色にする
- `.title-name`, `.title-tagline`:
  - イタリック指定（`font-style: italic`）
  - `title-name` は画面の約1/6を目安に設定（例: `font-size: clamp(56px, 16vh, 140px)`）
  - `title-tagline` はタイトル直下に配置し、可読性のためサイズ・字間・色を調整
- `.fade-in`:
  - 既存 `@keyframes fadeInUp` を再利用

3. ロゴ実装案
- 案A（推奨）: CSSでドーナッツロゴを描画
  - `radial-gradient` を使ってドーナッツ形状を表現
  - スプリンクルは複数色の小要素や重ねグラデーションで表現
- 案B: SVGロゴを背景として利用
  - 多色ロゴ管理がしやすい
  - 将来的な差し替えが容易

## 8. 受け入れ条件
- ボタンが表示されない。
- 画面クリックで `/people` に遷移できる。
- Enter/Space キーでも `/people` に遷移できる。
- 背景が一色である。
- 背景中央にドーナッツモチーフのロゴが表示される。
- ロゴが2色以上で構成され、可愛らしさが視認できる。
- `donuts` と `ドーナッツ～恋人相性チェッカー～` が中心表示される。
- `donuts` の文字サイズが画面高の約1/6目安で表示される。
- キャッチフレーズがアプリ名の直下に表示される。
- ページタイトル（`h1`）が表示されない。
- タイトル画面にフェードインが適用される。
- タイトル/キャッチフレーズがイタリック表示される。
- モバイル表示でも中央配置と可読性を維持する。
