# プロフィール選択 仕様書

## 1. 対象
- 対象ページ: 人物選択画面
- 対象ファイル: `../home/yamanashi/dateplanner/src/features/person-selector/PersonSelectorPage.tsx`

## 2. 目的
ユーザーが複数のプロフィールを作成し、アイコン・名前・重要度（高/中/低）を管理できる画面を提供する。プロフィールは重要度順に角丸長方形カードで表示し、編集・削除にも対応する。データはローカルストレージに保存し、リロード後も保持する。

## 3. 画面レイアウト仕様
- ページタイトル（上部）: `プロフィール選択`
- 画面構成比率:
  - タイトル領域: 20%
  - プロフィール一覧領域: 70%
  - 「新しいプロフィールを追加」ボタン領域: 10%
- 背景色 / バックグラウンドカラー: `#ffffcc`（指定値）
  - 備考: CSS上は5桁カラーのため描画互換のために `#ffffcc` をフォールバック利用する実装を推奨。

## 4. 機能要件
1. プロフィール作成
- 複数プロフィールを作成可能。
- 各プロフィール項目:
  - アイコン（ユーザー選択 + デフォルトアイコンあり）
  - 名前（自由入力）
  - 重要度（`高` / `中` / `低`）
- 「新しいプロフィールを追加」ボタン押下で入力フォームを表示。

2. プロフィール一覧表示
- 角丸長方形カードで表示。
- 並び順:
  - 第1キー: 重要度（高 > 中 > 低）
  - 第2キー: 名前のアルファベット順（同一重要度時）

3. 編集・削除
- 編集: 既存プロフィールのアイコン・名前・重要度を変更可能。
- 削除: 不要プロフィールを削除可能。

4. 永続化
- プロフィールデータをローカルストレージへ保存。
- ページリロード後も一覧が復元されること。

## 5. データ仕様（実装指針）
```ts
interface Person {
  id: string;
  icon: string;
  name: string;
  importance: "high" | "medium" | "low";
  createdAt: string;
}
```

- 重要度の表示ラベル:
  - `high` => `高`
  - `medium` => `中`
  - `low` => `低`
- ソート優先度マップ:
```ts
const importanceOrder = { high: 3, medium: 2, low: 1 };
```

## 6. 実装案（具体機能・特徴）
### 案A: シンプル実装（推奨）
- 画面下部に `新しいプロフィールを追加` ボタンを固定配置。
- ボタン押下でフォームを開閉（モーダルまたはインライン）。
- 一覧カード内に `編集` / `削除` ボタンを配置。
- 編集は「対象カードを編集モード化」して同じフォームUIを再利用。
- 特徴:
  - 実装コストが低い
  - 学習しやすい（状態管理が直感的）

### 案B: モーダル分離実装
- 作成フォームと編集フォームをモーダルに分離。
- 背景スクロール制御、Escape閉じる等を追加。
- 特徴:
  - UXが明確
  - ただし実装とテストがやや重い

## 7. 実装方法（手順）
1. 型・コンテキスト拡張
- `Person` 型に `icon` と `importance` を追加。
- `addPerson` / `updatePerson` / `deletePerson` をコンテキストに定義。

2. 永続化処理
- `loadPeople()` で既存データを読み込み。
- 旧形式データはデフォルト値（例: `icon="🙂"`, `importance="medium"`）で補完。
- `savePeople()` で作成・編集・削除後に必ず保存。

3. 画面レイアウト実装
- タイトル20% / 一覧70% / 追加ボタン10%をCSS GridまたはFlexで実現。
- 背景色に `#ffffcc`（必要に応じ `#ffffcc` フォールバック）を設定。

4. 作成フォーム実装
- 初期表示は閉じる。
- 追加ボタン押下で開く。
- 入力項目:
  - アイコン選択（プリセット + 任意入力）
  - 名前入力
  - 重要度選択（高/中/低）
- バリデーション: 名前必須。

5. 一覧とソート実装
- 配列を以下でソートして描画:
  1. `importanceOrder` 降順
  2. `name.localeCompare(name, "en")`
- 角丸長方形カードで表示。

6. 編集・削除実装
- 編集ボタンで編集モードに入り、保存で更新。
- 削除ボタンで確認後に削除。

7. テスト
- 作成・編集・削除・ソート・永続化のユースケースをテスト。

## 8. 難易度
- 総合難易度: **中級（3.5 / 5）**

難易度内訳:
1. フォーム表示切替（追加ボタン -> フォーム表示）: 易
2. アイコン/重要度入力 + バリデーション: 易
3. ソート（重要度 + 名前）: 易
4. 編集・削除の状態遷移: 中
5. ローカルストレージ互換対応（旧データ補完）: 中
6. レイアウト比率 20/70/10 の維持: 中
