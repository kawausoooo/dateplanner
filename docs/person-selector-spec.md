## 2. 目的
ユーザーが複数プロフィールを作成・編集・削除し、アイコン・名前・重要度（高/中/低）を管理できるようにする。プロフィールを見やすく表示し、データをローカルストレージで保持する。

## 3. 画面仕様
- ページ上部タイトル: `プロフィール選択`
- 背景色 / バックグラウンドカラー: `#ffffcc`
- レイアウト比率（縦方向）:
  - タイトル領域: 20%
  - プロフィール一覧領域: 70%
  - 追加ボタン領域: 10%

## 4. 機能要件
1. 複数プロフィール作成
- 各プロフィール項目:
  - アイコン（選択式 + デフォルト）
  - 名前（自由入力）
  - 重要度（`高` / `中` / `低`）

2. 新規追加フロー
- 下部の `新しいプロフィールを追加` ボタン押下で入力フォーム表示。
- フォームでアイコン・名前・重要度を設定して作成。

3. 一覧表示
- 角丸長方形カードで表示。
- 並び順:
  - 第1キー: 重要度（高 > 中 > 低）
  - 第2キー: 名前アルファベット順（同一重要度時）

4. 編集・削除
- 編集: アイコン・名前・重要度を変更可能。
- 削除: 不要プロフィールを削除可能。
- 編集/削除ボタン:
  - 横一列・横書き
  - 角丸四角
  - 編集ボタンは薄い青（例: `#93c5fd`）
  - 削除ボタンは薄い赤（例: `#fca5a5`）

5. 文字サイズ優先
- アイコンと名前を、編集/削除ボタン文字より大きく表示。

6. 重要度による色分け
- プロフィール色は重要度で固定:
  - 高: 橙色（例: `#fb923c`）
  - 中: 黄緑色（例: `#a3e635`）
  - 低: 空色（例: `#7dd3fc`）

7. 永続化
- プロフィールデータは `localStorage` に保存。
- リロード後も保持。

8. 起動導線
- 起動時: `タイトル画面 -> プロフィール画面`。
- タイトル画面要件:
  - アプリロゴを表示
  - `スタート` ボタンを表示
  - `スタート` 押下でプロフィール画面へ遷移

9. メイン画面要件
- プロフィール画面で `メインに進む` 押下時にメイン画面へ遷移。
- プロフィールが0件の場合は `メインに進む` を無効化。
- メイン画面では「選択中プロフィール情報（アイコン・名前・重要度）」を表示。

10. 選択中プロフィールの強調表示
- プロフィール画面で選択中の人物カードは、通常より分かるように濃い色で表示する。

11. フェードイン演出
- プロフィール選択画面を開いたとき、主要表示要素（タイトル直下のコンテンツ、一覧、追加ボタン、フォーム）がフェードインする。
- 必要に応じて、要素ごとにわずかな遅延を設けて視認性を高める。

## 5. データモデル（実装指針）
```ts
export type PersonImportance = "high" | "medium" | "low";

export interface Person {
  id: string;
  icon: string;
  name: string;
  importance: PersonImportance;
  createdAt: string;
}
```

- 重要度ラベル:
  - `high` => `高`
  - `medium` => `中`
  - `low` => `低`
- ソート優先度:
```ts
const importanceOrder = { high: 3, medium: 2, low: 1 };
```
- 重要度色マップ:
```ts
const importanceColors = {
  high: "#fb923c",
  medium: "#a3e635",
  low: "#7dd3fc",
};
```

## 6. 実装案（具体機能・特徴）
### 案A: 重要度固定色 + CSSフェードイン（推奨）
- 色を `importance` から直接決定。
- 選択中カードは同系色の濃いトーンで強調。
- 画面表示時に `opacity` + `transform` のCSSアニメーションでフェードイン。
- 特徴: 実装がシンプルで保守しやすい。

### 案B: CSSクラス + 段階表示
- `importance-high` / `importance-medium` / `importance-low` クラスを付与。
- `selected` クラスで濃色化。
- `animation-delay` で一覧・ボタン・フォームを段階表示。
- 特徴: 見た目の演出を細かく調整しやすい。

## 7. 実装方法
1. 型と状態管理
- `Person` に `icon`, `name`, `importance` を保持。
- `addPerson`, `updatePerson`, `deletePerson`, `selectPerson` を実装。

2. UIレイアウト
- タイトル20% / 一覧70% / 追加10% をCSSで実装。
- 背景を `#ffffcc` に固定。

3. フォーム実装
- 追加ボタンでフォーム表示。
- アイコン、名前、重要度（高/中/低）を入力。

4. ソート
- `importanceOrder` 降順 -> `name.localeCompare(..., "en")` で並べ替え。

5. 編集/削除ボタン
- `display: flex; flex-direction: row;` で横並び。
- `border-radius` で角丸。
- 編集: 薄い青、削除: 薄い赤。

6. 重要度色反映
- 重要度ごとにカード色を設定。
- 選択中カードは濃い色に変化させる（背景/枠線/左帯など）。

7. 永続化
- `localStorage` 保存/読込。
- 旧データは `importance` を補完。

8. 画面遷移
- `/` をタイトル画面に設定。
- タイトルの `スタート` で `/people` へ。
- プロフィール画面の `メインに進む` で `/main` へ。

9. メイン画面表示
- `selectedPersonId` から選択プロフィールを取得して表示。

10. フェードイン実装
- `.fade-in` 系クラスを用意し、`@keyframes` で `opacity: 0 -> 1` を設定。
- 必要なら `transform: translateY(8px) -> translateY(0)` を併用。
- 一覧・追加ボタン・フォームに段階的な `animation-delay` を付与。
